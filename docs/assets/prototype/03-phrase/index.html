What this page cannot show

It cannot show that the sound resembles a real setar: there is no measured specimen, no recording comparison and no listening study. The observation is a synthetic far-field monopole/dipole model of a synthetic body, not a calibrated microphone. The wall-clock speed is one run on one machine, not a realtime qualification.
