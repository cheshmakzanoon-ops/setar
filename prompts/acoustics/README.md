# Body and acoustic implementation prompts

These prompts are proposed work orders, not executable features or claims of completed tests. Read [AGENTS.md](../../AGENTS.md), the [master roadmap](../../docs/ROADMAP.md), and the exact linked technical chapter before implementation.

The [work-order collection](01-implementation-work-orders.md) covers admissible materials, geometry/ports, FEM convergence, modal normalization, FRF identification, energy-conserving coupling, cavity tests, radiation impedance, PML, microphone observation, passive reduction, and portable exchange.

Choose one bounded order. Confirm its entry evidence, inspect existing code before naming new interfaces, preserve unrelated changes, and distinguish synthetic fixtures from specimen validation. A prompt does not grant permission to acquire equipment, modify an instrument, publish measurements, or install paid software.
