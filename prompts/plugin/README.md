# Plugin and real-time task prompts

These prompts cover bounded integration work, independent review, and diagnosis.
Select the relevant contract and actual capability before starting; a prompt
does not imply that its named subsystem already exists.

- [Implement one host contract](implement-host-contract.md).
- [Review compatibility and callback safety](review-plugin-and-realtime.md).
- [Debug a host or event failure](debug-host-and-event-failure.md).

Read [AGENTS.md](../../AGENTS.md), [plugin architecture](../../docs/plugin/01-architecture-and-boundaries.md),
and the relevant [real-time contract](../../docs/realtime/README.md). Keep the
C++20 core independent of JUCE, preserve user work, and distinguish local tests,
observed cross-platform runs, generic validator results, and manual DAW evidence.
No prompt authorizes signing, publishing, installing commercial software, or
changing repository permissions.
