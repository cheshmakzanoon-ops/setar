# Validation task prompts

Choose one bounded task and replace bracketed inputs with actual identifiers.
Do not ask a worker to implement every chapter at once. The prompts require
evidence and preserve the distinction between synthetic verification and empirical
validation.

- [Implement a metric or experiment](implement-evidence-pipeline.md): independent extractor checks and reproducible packets.
- [Review a claim](review-validation-claim.md): scope, uncertainty, leakage, statistics, and acceptance.
- [Debug a discrepancy](debug-acoustic-discrepancy.md): competing hypotheses and targeted interventions.

Read [AGENTS.md](../../AGENTS.md), the current source, and the linked chapter
before acting. Existing user changes remain untouched unless directly required
by the task. Missing data, tools, or platform access are reported as limitations,
not replaced with invented results. Publication and external data collection are
separate authorization decisions.
